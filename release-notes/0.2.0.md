# Folder Bridge Local 0.2.0

A dialog to combine clashing edits, and proper handling of folders and notes moved outside Obsidian.

## Conflict dialog (`5cf9e8d`)
- When you and someone else changed the **same lines** of a note (so the automatic merge cannot combine them), your version is saved, theirs is kept in `.folderbridge-trash`, and a dialog opens once Obsidian's save has finished.
- Each clash is a card with **your lines and theirs side by side**, labelled with your login name and "On the drive", with the changed words highlighted.
- Per clash: **Mine**, **Theirs**, **Both, mine first**, **Both, theirs first**, or **Edit…** (free text).
- A live, **editable preview** of the whole resulting note, including any non-clashing changes that merged automatically (mentioned only when some did).
- Whole-note shortcuts: **Keep my version** (closes; nothing lost) and **Use their version** (your version is first saved as "(<login>'s version …)" in the trash folder).
- Keyboard: ↑/↓ between clashes, 1–4 to choose, Ctrl/Cmd+Enter to apply, Esc keeps yours. The layout stacks on narrow windows.
- Applying goes through `vault.process`: anything typed after the clash is three-way merged on top; if that is impossible nothing is written and the dialog says why. The open editor reloads to show the result.
- New helpers in `src/textFiles.ts`: `conflictRegions` (three-way regions with a base, two-way without) and `wordDiff`; `VirtualAdapter.keepTextCopy`.

## Moves made outside Obsidian (`9495394`)
- **Moves and renames are recognised as moves.** Each watcher batch pairs what vanished with what appeared: files by identical size and modification time (ties broken by name, ambiguous cases left alone), folders when at least half of their entries share names. Open tabs follow the moved note, and its cached metadata is kept, instead of the note closing as deleted. Links in other notes are not rewritten (only moves made inside Obsidian do that). New module `src/moveDetect.ts`.
- **A save never brings back a note that vanished.** If a note you are editing is moved or deleted on the drive before your save lands, your text is written to ".folderbridge-trash/<name> (unsaved edits <time>)" (one copy per note per session, updated on later saves) instead of recreating the file at its old place.
- **"Folder not found" instead of "offline".** When a mount is unreachable but the folder above it answers, the mounted folder was moved or renamed: the status bar ("1 not found"), the explorer marker, the settings row, notices and the error shown when opening a file all say so and point to **Edit mount…**.

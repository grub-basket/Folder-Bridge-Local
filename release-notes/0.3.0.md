# Folder Bridge Local 0.3.0

"What's in this mount?" — see where a mount's files are and trim it down in one click.

## Size report (`aa23a5c`)
- New report for each mount, from the mount folder's right-click menu (**What's in this mount?**), a button in the mount's settings row, or the command **What's in a mount? (size report)**.
- Totals: files, notes (Markdown, canvas, Bases), folders, and size on the drive.
- How long the last full check of the drive took and how many items it covered (every launch repeats that check in the background, so fewer items means less waiting on the network).
- The folders that hold most of the mount, biggest first (up to three levels deep), each with a share-of-mount bar, file and note counts, size, and a **Hide** button. A subfolder that is almost all of an already-listed parent is not listed twice.
- **Hide** adds the folder to the mount's ignore list. The folder leaves the vault immediately, with no disk or network access, and is never checked again.
- When at least half of the files are not notes and the mount shows all file types, a **Switch to notes only** button.
- Opening the report reads only Obsidian's index (no disk or network access).
- README section "What's in a mount? (making big mounts small)" and updated command list.

## Fixes (`0343c09`)
- Two quick edits to the same mount (for example two Hide clicks, or Hide then "Switch to notes only") no longer undo each other: edits are applied one after another to the current settings. This also covers **Hide … from this mount** in the file explorer menu.
- The report's "last full check" is cleared when a mount is pointed at a different folder, and shows the date when it is not from today.
- An ignore pattern starting with "/" now always means exactly that item from the mount root, even when its name contains "*".
